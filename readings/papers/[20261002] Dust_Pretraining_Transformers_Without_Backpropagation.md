# Dust: 역전파 없이 트랜스포머를 사전학습하기

- **원문**: [Dust: Pretraining Transformers Without Backpropagation](https://qlabs.sh/research/dust) (Q Labs Research 블로그형 논문, 2026-10)
- **저자**: Samip Dahal, Bishwas Mandal, Serdar Gülbahar, Akshay Vegesna (Q Labs, 4명)
- **코드**: [qlabs-eng/dust](https://github.com/qlabs-eng/dust) (MIT, Python. 저장소 생성 2026-10-02, 마지막 푸시 10-06, 별 278개, 2026-10-27 기준)
- **소개 글**: [GeekNews 토픽 34868](https://news.hada.io/topic?id=34868)
- **실험 환경**: GPT형 트랜스포머(기본 8층, 너비 512, 시드 3개), FineWeb, BPE-4096 토크나이저, 배치 16k 토큰(2,048토큰 × 8), 1 epoch, 모멘텀 SGD(상수 학습률)
- **읽은 날짜**: 2026-10-27
- **태그**: #ZerothOrder #EvolutionStrategies #Pretraining #Backprop #EGGROLL

## 한 줄 요약

가중치가 아니라 **활성값에 토큰마다 다른 잡음**을 넣으면, 순전파 한 번 안에서 토큰 수만큼의 탐색 후보(가상 집단)를 평가할 수 있다. 이 방식으로 역전파 없이 트랜스포머를 처음부터 학습했고, 작은 데이터(10만·100만 토큰)에서는 역전파보다 낮은 손실을 냈다. 다만 연산 효율은 저자들 스스로 "여러 자릿수" 부족하다고 인정한다.

## 방법

```mermaid
flowchart LR
  C["clean 순전파<br/>(결과 캐시)"] --> N["층 출력 활성값에<br/>토큰별 가우시안 잡음"]
  N --> L["토큰별 손실 감소량 c_s"]
  L --> R["보상 r_t = Σ γ^(s-t) c_s<br/>(뒤 토큰 손실까지 할인 합산)"]
  R --> E["보상 가중 잡음 평균<br/>= 층 출력 오차 추정"]
  E --> G["입력과 외적<br/>= 가중치 기울기 추정"]
  G --> U["SGD 업데이트"]
```

- **가상 집단**: 기존 진화 전략(ES)은 가중치를 여러 벌 복제해 후보를 만든다. Dust는 잡음을 활성값에 토큰 단위로 넣기 때문에 배치 안 토큰 하나하나가 서로 다른 후보가 된다. 복제 비용이 없다.
- **간섭 줄이기**: 층 종류별로 탐색 순전파를 나누고, 바뀌지 않은 계산은 clean 순전파 결과를 캐시해 다시 쓴다. 그래서 한 번의 탐색(draw)이 순전파보다 조금 싸다.
- **출력 헤드**: 캐시한 로짓에 직접 잡음을 넣어 싸게 큰 집단을 돌린다.
- **어텐션 내부**(Q, K, V, 게이트, 값 임베딩): 최종 손실 대신 어텐션 출력과의 정렬로 평가한다.
- **예외**: 잔차 혼합 스칼라 2L개만 일반 가중치 공간 ES로 학습한다.

## 결과 (원문 수치)

| 실험 | Dust | 역전파 | 비고 |
|---|---|---|---|
| 10만·100만 토큰 | 역전파보다 낮은 손실 | | 필요한 집단: 10만 토큰 수백, 100만 토큰 약 1,000 이상 |
| 2,000만 토큰 (멱법칙 피팅 극한) | 4.431 (95% 구간 3.89~4.58) | 4.633 | 외삽값. 저자도 "loosely constrained"라고 씀 |
| Adam, 100만 토큰 (극한) | 5.248 (95% 구간 5.17~5.30) | 5.361 | 외삽값 |
| 1,000만 토큰, 집단 16k, 2M 파라미터 | 5.171 | 5.180 | |
| 같은 조건, 7.3M | 5.065 | 5.066 | |
| 같은 조건, 38M | 5.036 | 5.015 | |
| 같은 조건, 243M | 5.086 | 5.048 | 가장 큰 모델이 최선은 아님 |

- **EGGROLL**(가중치 공간 ES의 최신 기법)과 비교: EGGROLL은 집단 16k에서도 100만~2,000만 토큰 구간 손실이 Dust보다 0.4~0.6 높다. Dust의 최소 집단(64)을 따라잡으려면 수천~약 10⁴배 집단이 필요하다는 것은 **외삽**이다.
- **기울기 방향**: 역전파 체크포인트(1,000만·1억·10억 토큰)에서 잰 코사인 유사도가 집단 크기 K에 따라 `c_max / sqrt(1 + c/K)` 꼴로 오른다(RMSE 0.06 미만). EGGROLL은 128k 집단에서도 헤드 제외 0.05 미만이다. 10억 토큰은 **방향 측정만** 했고 Dust로 그만큼 학습한 것은 아니다.

## 읽을 때 주의할 점

1. **"역전파를 이겼다"는 작은 데이터 얘기다.** 실측으로 앞선 구간은 10만·100만 토큰이다. 2,000만 토큰에서 앞선다는 것은 아직 내려가는 곡선에 대한 피팅 극한값이다.
2. **같은 연산량 비교가 아니다.** 집단 16,384는 업데이트마다 그만큼의 draw를 쓴다. 저자들은 "We do not attempt to make it compute-efficient enough to replace backprop today"라고 명시한다. 동일 손실 기준 실행 시간·에너지·메모리 비교는 없다(GeekNews 댓글에서도 같은 지적).
3. **역전파보다 낮은 손실이 나오는 이유는 저자들도 설명하지 못했다.** 작은 데이터에서 잡음이 정규화 역할을 했을 가능성 같은 해석은 원문에 없다(미검증 추측).
4. **규모**: 최대 243M 파라미터, 2,000만 토큰. 공개 코드는 "최소 구현"으로, 논문 실험의 실행 최적화는 빠져 있다. 기본 집단 16,384는 GPU 8장, 256은 1장 설정이다.

## 커뮤니티 반응 (GeekNews 댓글 요약)

- 회의: 신경망 목적함수는 대체로 매끄러워 기울기가 유용하고, 파라미터가 많을수록 기울기의 이점이 커진다. 0차 방법이 비볼록성을 근본적으로 해결하지도 않는다.
- 쓸 자리: 시뮬레이터처럼 기울기가 없는 환경, 깊이 방향 파이프라인 병렬화(역방향 단계가 없어 층 간 대기가 줄어듦).
- 혼합안: 0차 탐색으로 후보를 찾고 1차 학습으로 정착시키거나, 역전파 체크포인트를 Dust로 미세조정.

## 우리 쪽과의 거리

당장 가져갈 것은 없다. 우리는 사전학습을 하지 않고, 공개 모델을 서빙·평가하는 쪽이다. 볼 만한 연결점은 하나다.

- **미분할 수 없는 목적함수의 미세조정**: 판정기 점수, 그래프 조회 성공 여부처럼 기울기가 없는 보상으로 작은 모델을 조정해야 할 때, 가중치 복제 없이 활성값 잡음으로 후보를 늘리는 아이디어는 메모리 측면에서 의미가 있다. 다만 원문은 사전학습 손실(다음 토큰 예측)만 다뤘고, 보상이 시퀀스 단위인 경우는 실험하지 않았다.

## 파생 자료 (2026-10-27 확인)

### Noise: 역전파 없는 사전학습 스피드런

Dust 공개 후 Q Labs가 연 공개 경쟁이다. [qlabs-eng/noise](https://github.com/qlabs-eng/noise) (MIT, 2026-10-12 생성, 별 415개, 포크 54개, 마지막 푸시 10-26). 소개 페이지는 [qlabs.sh/noise](https://qlabs.sh/noise).

- **고정**: Dust의 37.7M 파라미터 트랜스포머, FineWeb 3,000만 토큰(10-22 이전에는 Dust의 1,000만 토큰), Dust 검증셋 교차 엔트로피, 8xH100 1노드, 1 epoch.
- **규칙**: autograd(역방향·순방향 모드 모두)와 손으로 쓴 역방향 계산 금지. 오차 신호는 순전파로 손실에 대어 재고, 비선형 부분을 **최대 한 단계**만 거칠 수 있다. 블록을 따라 연쇄로 기여도를 넘기는 것을 막는 규칙이다. 미분 불가능한 부분이 있는 네트워크에도 쓸 수 있어야 한다는 취지로 판정한다.
- **트랙**: ① 검증 손실 최저 ② 손실 3.5 도달 시간 ③ 아키텍처 자유.

README 기록표(2026-10-27 시점):

| 구분 | 검증 손실 | 시간 | 방법 |
|---|---|---|---|
| 역전파, Adam + lr cooldown | 3.419 | | 기준선 |
| 역전파, ANVIL II + Adam | 3.340 | | 기준선 |

- **원 논문 Dust 그대로는 역전파에 크게 뒤진다** (3.767 대 3.419). 같은 모델·데이터에서 Adam끼리 비교한 실측이다.
- 트랙 1 최고 기록 3.338은 역전파 최선(3.340)과 0.002 차이다. seed 0 단일 실행이라 이긴 것으로 읽기 어렵다.
- 상위 기록은 Dust의 "토큰별 잡음" 추정기가 아니라 국소 기여도 할당 기법들(Boost, Cut, future-token probe)이다. "역전파 없이"의 범위가 Dust보다 넓다.

## 결론

Dust의 기여는 효율이 아니라 **가능성 증명**이다. 활성값 잡음과 토큰 단위 가상 집단으로 0차 방법의 고질적 문제(집단 크기와 차원의 저주)를 크게 줄였고, 같은 0차 계열인 EGGROLL보다는 확실히 낫다. 역전파 대체 여부는 2,000만 토큰 이상 실측과 같은 연산량 비교가 나오기 전까지 판단하지 않는다. Noise 3,000만 토큰 실측에서 원 Dust는 역전파보다 0.35 높았고, 역전파와 같은 수준에 닿은 것은 Dust 위에 국소 기여도 기법을 얹은 공동체 기록이다.
