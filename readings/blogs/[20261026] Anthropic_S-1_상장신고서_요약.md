- **원문**: [Anthropic, PBC Form S-1](https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm) (SEC EDGAR)
- **제출**: 2026-10-26, 예비 투자설명서 (공모가, 주식 수, 일부 금액은 빈칸)
- **상장 예정**: Nasdaq Global Select Market, 종목 코드 `ANT`, Class A 보통주
- **주관사**: Goldman Sachs, Morgan Stanley, J.P. Morgan, Citigroup 외 18곳
- **읽은 날짜**: 2026-10-27 (투자설명서 요약, 재무 요약, 분기 실적, 위험 요인 요약, 재무제표 주석 일부)
- **태그**: #Anthropic #IPO #S-1 #LLM비즈니스 #Compute #PBC #지배구조

## 한 줄 요약

매출이 2023년 4,100만 달러에서 2026년 상반기 163억 달러로 늘었고, 2026년 2분기에 처음으로 영업이익(9.74억 달러)을 냈다. 매출의 80%가 토큰 사용량 과금이다. 순손실이 큰 것은 기업가치 상승에 따른 전환사채 평가손실 때문이고 현금 지출이 아니다. 지배구조는 장기이익신탁(LTBT)이 이사회 과반을, 공동창업자 7명의 LLC가 의결권 50.1%를 갖는 형태라 일반 주주의 영향력은 사실상 없다.

## 사업 서술의 핵심

- **컴퓨트를 하나의 풀로 운영**: AWS Trainium, Google TPU, NVIDIA GPU, AMD GPU를 섞어 쓰고, 연구, 학습, 고객 서빙, 사내 사용 사이에서 한계 효용이 가장 큰 곳으로 컴퓨트를 옮긴다고 설명한다. 자체 데이터센터도 늘릴 계획이다
- **Virtual Collaborator**: 사람 옆에서 여러 단계의 일을 전문가 수준으로 하는 AI를 이렇게 부른다. 대표 사례로 Claude Code를 들고, 지식 노동자용으로 같은 구조를 옮긴 것이 Claude Cowork다
  - Claude Cowork는 2026년 1월 리서치 프리뷰로 나왔고, 같은 시점의 Claude Code(2025년 2월 프리뷰)보다 빠르게 채택됐다고 적는다
  - 2026년 9월부터 Claude Cowork와 Claude.ai를 하나의 앱으로 합치는 중이다
- **closing the loop**: 실험 실행, 학습 데이터 생성, 평가와 안전 감사 자동화, 코드 작성·리뷰까지 다음 모델 개발에 Claude를 쓴다. 원문은 이것을 가장 큰 구조적 이점 중 하나로 든다
- **가격 인하로 사용량 확대**: Claude Opus 5.5가 Claude Opus 5보다 작업당 고객 비용을 약 40% 줄였다고 적는다
- **유통**: AWS, GCP, Azure 세 곳 모두에서 제공한다. 고객과는 직접 계약하고 CSP에 수수료를 내는 구조라 채널 충돌을 피하고 가격을 직접 정한다. Accenture, Deloitte, KPMG, PwC 같은 SI와 Salesforce, Snowflake 같은 데이터 플랫폼도 유통 경로다. 중견기업용 AI 서비스 회사 Ode with Anthropic을 사모펀드와 함께 세웠다
- **새 시장**: 신약 개발과 로보틱스를 든다. Model Hardware Standard로 에이전트가 현미경, 액체 분주기, 로봇 팔 같은 장비를 다루게 한다고 적는다

## 지배구조

### 주식 종류

| 종류 | 의결권 | 경제적 권리 | 보유자 |
|---|---|---|---|
| Class A | 주당 1표 | 있음 | 공모 투자자, 기존 우선주 일부 |
| Class N | 없음 (법이 요구할 때만) | 있음 | 주로 전략적 사업 파트너. 제3자에게 팔면 Class A로 전환 |
| Class T | 이사회 과반(Class T 이사) 선임·해임 | 없음 | LTBT (1주) |
| Class F | 전체 의결권의 50.1% (Class T 이사 외 이사 선임 포함) | 없음 | 공동창업자 7명의 Founder LLC (1주) |
| Class E | 일부 사안에만 주당 1표 | 없음 | 공동창업자를 뺀 직원 |

- **PBC(공익법인)**: 주주의 금전적 이익, 회사 활동에 영향받는 사람의 이익, 회사 목적("인류의 장기적 이익을 위한 첨단 AI의 책임 있는 개발과 유지")을 함께 고려할 의무가 이사에게 있다
- **LTBT**: 금전적 이해관계가 없는 의결 수탁자 5명으로 구성되고, AI 안전, 국가안보, 공공정책, 사회적 기업 전문가로 채운다. 이사를 고르는 역할만 하고 일상 경영이나 전략에는 관여하지 않는다
- **Founder LLC**: Dario Amodei, Daniela Amodei, Tom Brown, Jack Clark, Jared Kaplan, Sam McCandlish, Christopher Olah. LTBT와 Founder LLC가 함께 이사 전원을 선임할 수 있다
- **controlled company**: Nasdaq 기준의 지배주주 회사라 일부 지배구조 요건을 면제받을 수 있다. 실제로 면제를 쓰는 것은 지명·지배구조위원회(전원 독립이사가 아님) 하나라고 적는다

### 공익 기금

- Class N 주식 846,840,960주(2026-06-30 완전희석 기준 5%)를 100% 자회사 Anthropic Public Benefit Fund에 넣었다
- 주가가 직전 기준가보다 50% 오를 때마다 발행주식의 최대 2%를 추가로 넣을 수 있는 틀을 이사회가 승인했다. 첫 기준가는 공모가다
- 공동창업자는 각자 보유 지분의 80%를 기부하기로 약속했다. 직원 기부 매칭 프로그램도 있다

## 공모 조건

- 회사가 신주를 팔고, 기존 주주도 구주를 판다. 구주 매각 대금은 회사로 들어오지 않는다
- 공모가 범위, 주식 수, 조달 예정액은 모두 빈칸이다
- 사용처: 운영자금, 컴퓨트와 인프라 투자, 인재 채용과 유지, 인수·투자(현재 확정된 건 없음), RSU 정산에 따른 원천징수 세금 납부
- 2026-09-17에 Class A와 Class N을 10대 1로 액면분할, Class T를 1,000대 1로 병합했다
- 공모 직전에 우선주는 Class A 또는 Class N으로, AWS 보유 전환사채는 Class N으로 바뀐다(보유 한도를 넘지 않는 범위에서)

## 위험 요인 요약에서 눈에 띄는 것

원문 요약 목록 18개 중 이 회사에만 해당하는 것들이다.

- 최고 수준의 모델을 계속 만들지 못하면 사업이 흔들린다
- 컴퓨트를 충분히 확보하지 못하거나 작업 간 배분을 잘못하면 경쟁력 있는 모델을 학습하거나 고객을 충분히 서빙하지 못한다. 컴퓨트에 들어가는 핵심 자원 공급 제약도 따로 적었다
- 모델이 의도하지 않게, 정렬되지 않게, 자율적으로 행동해 아무도 지시하지 않은 해로운 행동을 할 수 있다
- CSP와 공급사 몇 곳에 의존하는데, 이들이 투자자이자 고객이기도 해 이해 충돌이 생길 수 있다
- 매출과 매출채권이 소수 고객과 유통 채널에 몰려 있다. 2026-06-30 매출채권의 13%가 Customer A, 10%가 Customer C다
- 주식 구조 때문에 Class A 주주는 경영권 변경을 포함한 중요한 결정에 사실상 영향을 줄 수 없다
- PBC로서의 균형 의무가 단기, 중기, 장기 재무 성과와 부딪힐 수 있다

## 읽을 때 감안할 것

- **예비 신고서다.** 공모가, 주식 수, 3분기 매출, 컴퓨트 약정 총액이 빈칸이고, 수정 신고서에서 바뀔 수 있다
- **2026년 수치는 감사를 받지 않았다.** 연간(2023~2025)만 감사를 받았고 반기와 분기는 미감사다
- **조정 영업이익(non-GAAP)은 회사가 정의한 지표다.** 주식보상비용 등 무엇을 뺐는지는 MD&A의 조정표에 있고, 이 노트에서는 조정표를 읽지 않았다
- **NRR 900%는 고객이 1년 만에 평균 9배를 쓴다는 뜻이다.** 기준 기간 매출이 아주 작은 고객이 많으면 값이 크게 나온다. 매출 규모별 분포는 공개하지 않았다
- **"역사상 가장 빠른 기업 채택"**, "산업화, 전기, 반도체, 인터넷보다 큰 영향" 같은 표현은 투자설명서의 회사 주장이다
- 이 노트는 Claude가 원문을 읽고 정리했다. 원문에 나온 수치만 옮겼고, 비율과 배수는 원문 수치로 계산한 값이다

## 가져갈 지점

- **LLM 사업은 사용량 과금이 중심이다.** 매출의 80%가 토큰 과금이고, 매출 대비 컴퓨트 비용이 1년 만에 160%에서 55%로 내려왔다. 모델 가격 인하가 사용량 증가로 이어진다는 설명은 [무신사 Prompt Caching 비용 절감기](./[20260707]%20무신사_LLM비용_64절감_Prompt_Caching.md)처럼 고객 쪽에서 토큰 비용을 관리하는 이야기의 반대편이다
- **여러 칩을 섞어 하나의 풀로 운영하는 방식**은 [서빙 구조가 LLM 처리량을 바꾸는 방식](./[20260908]%20Notion_서빙구조가_LLM_처리량을_바꾸는_방식.md)과 [DeepInfer 정리](../repos/[20261016]%20deepseek-ai_DeepInfer_DeepSeek전용_추론엔진_vLLM비교.md)에서 본 서빙 효율 문제를 회사 단위로 키운 것이다
- **에이전트가 매출의 중심이 됐다.** 사업 서술이 Claude Code와 Cowork를 축으로 짜여 있다. 코딩 에이전트에서 시작해 일반 업무 에이전트로 넓히는 순서를 회사 전략으로 명시했다

## 결론

S-1은 Anthropic이 매출 규모와 컴퓨트 효율 면에서 손익분기점을 넘었다는 것을 처음 숫자로 공개한 문서다. 순손실 수치는 평가손실이 대부분이라 영업손익과 조정 영업손익을 봐야 한다. 투자 관점에서는 지배구조가 가장 큰 변수다. Class A를 사도 경영에 영향을 줄 수 없다는 것을 회사가 직접 위험 요인으로 적었다.
