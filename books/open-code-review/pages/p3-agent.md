묶음별 리뷰 에이전트와 도구 호출 루프, 리뷰 도구를 다룬다.

| 장 | 핵심 |
|---|---|
| 06. 리뷰 에이전트 본체 | `internal/agent`의 `Agent`는 diff를 읽고, 리뷰 대상을 고르고, 묶음마다 하위 작업을 띄워 계획 단계와 여러 라운드의 본 리뷰를 돌린 뒤, 파일별 커버리지와 코멘트를 모아 돌려준다. |
| 07. llmloop: 도구 호출 루프와 컨텍스트 압축 | `internal/llmloop` 패키지는 "LLM에 요청하고, 도구 호출을 실행하고, 결과를 대화에 붙여 다시 요청한다"는 반복을 한 곳에 모은 공통 엔진이다. |
| 08. 리뷰 도구 세트와 MCP 확장 | 리뷰 에이전트가 쓸 수 있는 도구는 JSON 카탈로그 하나에 정의되고, 템플릿이 그중 일부를 이름으로 골라 모델에 보여 주며, 실제 실행은 Go 레지스트리에 등록된 provider가 맡는다. |
